# Trabalhar no Ebookfy

Leia o [guia de contribuição](CONTRIBUTING.md) e consulte `ebook.toml` para o exemplo e `manual/ebook.toml` para o manual. O capítulo do manual, a skill da etapa e o CLI devem descrever o mesmo comportamento. Preserve as permissões de acesso do repositório.

O framework e seu manual usam a mesma versão. Ao alterar a distribuição, valide o tarball instalado fora deste checkout. O starter kit recebe as skills publicadas por meio de npx skills add.
